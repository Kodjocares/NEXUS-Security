# Contributing to NEXUS Security

## Research Contributions Welcome

This is an academic research project. Contributions that advance the research goals are especially valued.

### Priority Areas
- **New market profiles** — risk data for additional West African countries
- **Risk model improvements** — refined weighting, additional factors
- **Threat detection** — new attack pattern signatures for the Sentinel module
- **IR playbooks** — sector-specific response procedures for SMEs
- **Localization** — French translation for Francophone West Africa

### How to Contribute
1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Commit your changes: `git commit -m 'Add: description'`
4. Push to branch: `git push origin feature/your-feature`
5. Open a Pull Request

### Code Style
- Keep components modular (one responsibility per file)
- Use the theme tokens from `src/theme.js` — no hardcoded hex colors
- Maintain the JetBrains Mono / cyberpunk aesthetic
- All AI prompts should include West Africa SME research framing

### Ethical Guidelines
All contributions must comply with responsible disclosure principles.
No contributions that enable unauthorized access or harm.
